# Everything the offline half of this repository needs: the unit tests, the
# grasp benchmark, the calibration and inspection analyses, the tuning harness.
# No ROS, no simulator.
#
# Deliberately unpinned. Every stochastic step takes a fixed seed, which is what
# makes the results reproducible -- not the library versions. The benchmark
# reproduces on numpy 1.21 / scipy 1.8 (WSL Ubuntu 22.04, Python 3.10) and on
# numpy 1.26 / scipy 1.13 (Windows, Python 3.9), and pinning would hide it if
# that ever stopped being true.
numpy
scipy
pyyaml

# The Modbus bridge and its transport tests.
#
# Pinned, unlike the numeric stack above, because this is an API dependency
# rather than a numerical one and the API moved. pymodbus 3.9 renamed
# ModbusSlaveContext to ModbusDeviceContext and the `slave=` keyword to
# `device_id=`, and 4.0 removed the aliases; 2.x is a different library again.
# `>=3.0` was the original constraint and CI duly installed a 4.x and failed
# to import, which is the whole argument for pinning an interface.
pymodbus>=3.6,<3.9
